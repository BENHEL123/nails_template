# NAILS by Ульяна — лендинг-шаблон с онлайн-записью

Mobile-first лендинг для частного мастера (маникюр/педикюр/репетитор и т.п.).
Один шаблон → под каждого клиента меняются фото, видео, прайс и тексты.

## Структура

```
nails-template/
├─ preview.html        # витрина: три типа сайта и панели (для показа клиенту)
├─ index.html          # сайт, тип A — светлый «clean girl» (мастер маникюра)
├─ styles.css
├─ script.js
├─ variant-b/          # сайт, тип B — тёмный «editorial luxe» (мастер маникюра)
│  ├─ index.html
│  ├─ styles.css
│  └─ script.js
├─ variant-tutor/      # сайт, тип C — «academic modern» (репетитор)
│  ├─ index.html
│  ├─ styles.css
│  └─ script.js
├─ variant-tutor-b/    # сайт, тип D — «bright edtech» (репетитор)
│  ├─ index.html
│  ├─ styles.css
│  └─ script.js
├─ privacy.html        # политика конфиденциальности (152-ФЗ)
├─ admin/              # панель мастера маникюра
│  ├─ index.html
│  ├─ admin.css
│  └─ admin.js
├─ admin-tutor/        # панель репетитора
│  ├─ index.html
│  ├─ admin.css
│  └─ admin.js
├─ shared/
│  ├─ store.js         # общий модуль: график, слоты, услуги, записи, повторы
│  └─ booking.js       # общий движок записи (форма, слоты, валидация)
└─ assets/

   └─ video/           # сюда кладутся ролики (пока пусто)
```

## Типы сайта

| | Тип A — «clean girl» | Тип B — «editorial luxe» | Тип C — «academic» |
|---|---|---|---|
| Для кого | мастер маникюра | мастер маникюра | репетитор |
| Настроение | светлый, нюд, воздух | тёмный, кофейный, золото | кремовый, индиго, медь |
| Шрифты | Cormorant + Manrope | Playfair Display + Manrope | Literata + Inter |
| Портфолио / блоки | 3D-карусель | лента-фильм | прогресс-бары и результаты |
| Прайс | карточки-строки | нумерованный список | карточки + пакеты занятий |
| Фишки | reels-блок | бегущая строка, цитаты | пробное занятие, повтор занятий |

**Тип D — «bright edtech»** (`variant-tutor-b/`): тоже репетитор, но другой характер —
светлый фон, крупная геометрия, индиго и лайм, карточка прогресса ученика, тумблеры
«пробное занятие» и «каждую неделю». Оба репетиторских шаблона используют одни и те же
данные и один движок записи, поэтому мастеру достаточно выбрать внешний вид.

Все типы используют **один движок данных и записи** (`shared/store.js` + `shared/booking.js`).
Чтобы переключить тип, достаточно взять нужную папку.

Новый тип сайта добавляется так: своя вёрстка и стили + подключение двух общих скриптов
и вызов `NailsBooking.init()`.

## Репетитор: что особенного

Тип C отличается от бьюти-шаблонов не только дизайном, но и логикой:

- **Предметы вместо услуг** — с уровнями (`9 класс`, `ОГЭ`, `B1–B2`).
- **Пробное занятие** — отдельная галочка в форме, помечается в заявке.
- **Повторяющиеся занятия** — «заниматься каждую неделю в это время». Система проверяет,
  что окно свободно на все недели серии, и создаёт серию занятий (4 / 8 / 12 недель).
- **Пакеты занятий** — скидки за объём (4 / 8 / 12 занятий).
- **Форматы** — онлайн, у преподавателя, выезд к ученику.
- **Часовой пояс** — определяется автоматически для онлайн-занятий.
- **Домашние задания и долги** — в панели репетитора.

Панель репетитора (`admin-tutor/`) живёт в отдельном хранилище (`nails-tutor-v1`),
поэтому демо-данные маникюра и репетитора не смешиваются. Экраны: расписание с повторами,
ученики (уровень, цель, заметки, история), оплаты и долги, настройки (цены, график, пакеты, уведомления).

## Надёжность записи

- **Защита от двойной записи.** Перед сохранением окно проверяется повторно — если его
  заняли, пока клиентка заполняла форму, она увидит «Это время только что заняли»
  и список окон обновится.
- **Живая синхронизация.** Мастер работает в панели (подтверждает, переносит, закрывает день),
  а открытый сайт обновляет свободные окна без перезагрузки — через `storage`-событие
  и возврат на вкладку.
- **Проверка при отправке** берёт свежие данные, а не те, что были при загрузке страницы.
- **Honeypot** в форме отсекает простых спам-ботов.


## Как связаны сайт и панель

Оба используют `shared/store.js` — единый источник данных:

- мастер меняет цены и график в панели → на сайте обновляются прайс и свободные окна;
- клиентка выбирает окно на сайте → запись падает в панель в «Ждут ответа» с уведомлением;
- занятое время сразу исчезает из слотов на сайте.

В прототипе данные лежат в localStorage под общим ключом. При подключении бэкенда
`NailsStore` заменяется на вызовы API, а интерфейс остаётся тем же:
`NailsStore.freeSlots(...)`, `NailsStore.addBookingFromClient(...)`.

## Что заменить под клиента

1. **Телефон** — в `index.html` и `privacy.html` заменить `+79990000000` и текст номера.
2. **Соцсети** — ссылки `t.me/your_nickname` и `instagram.com/your_nickname`.
3. **Имя мастера, адрес, время работы** — по всему `index.html`.
4. **Фото работ** — положить в `assets/img/` и заменить пути в массиве `WORKS` в `script.js`.
   Пропорция фото — 3:4, формат `.jpg`/`.webp`.
5. **Фото мастера и обложка** — заменить `master-placeholder.svg` и `hero-placeholder.svg`.
6. **Видео** — три файла: `assets/video/clip-1.mp4`, `clip-2.mp4`, `clip-3.mp4`.
   Требования: вертикальные 9:16, 5–10 секунд, без звука, сжатые (H.264, ~1–2 МБ).
   Пока файлов нет — показывается постер `video-placeholder.svg`.
7. **Прайс и услуги** — правятся в панели («Услуги и цены»), сайт подхватывает автоматически.
   Стартовые значения — в `shared/store.js` (блок `services`).
8. **Отзывы** — секция `#reviews`.

## Подключение бэкенда

В `script.js` есть константа:

```js
var BOOKING_ENDPOINT = ''; // '' — демо, '/api/booking' — боевой режим
```

Пока пусто, форма работает в демо-режиме: данные уходят в консоль.
Указываете URL — форма шлёт `POST` с JSON:

```json
{
  "name": "Ксения",
  "phone": "+7 (999) 123-45-67",
  "service": "manicure-gel",
  "serviceText": "Маникюр + покрытие гель-лак — 1 800 ₽",
  "datetime": "2026-10-10T15:00",
  "comment": "Хочу френч",
  "privacy": true,
  "page": "/",
  "sentAt": "2026-10-04T12:00:00.000Z"
}
```

## Уведомления — Telegram опционален

Важно: **сайт не привязан ни к какому мессенджеру.** Фронтенд просто отправляет заявку
на API. Канал доставки настраивается на бэкенде и может быть любым:

- **Web Push** — основной канал: бесплатно, приходит мгновенно, работает на Android
  и на iPhone (если панель добавлена на экран «Домой»);
- e-mail (SMTP) — копия заявки, универсально;
- Telegram-бот — **по желанию мастера**, если есть доступ и удобно;
- админка сама по себе: заявка уже лежит в панели и в уведомлениях.

СМС не используем: канал дорогой и нестабильный для рассылок.

Если мастер не пользуется Telegram — ничего не ломается, просто выбирается другой канал.

## Панель мастера (admin/)

Мобильное приложение-панель для ежедневной работы. В прототипе данные хранятся
в localStorage, при подключении бэкенда заменяются на API.

**Экраны:**

- **Сегодня** — расписание дня, блок «Ждут ответа», свободные окна, закрытие дня.
- **Клиенты** — база с поиском, заметки о клиентке, история, «Записать снова».
- **Касса** — доход за день, неделю и месяц, список выполненных визитов.
- **Ещё** — услуги и цены, график работы, уведомления, портфолио, QR на сайт.

**Логика:**

- Свободные окна считаются из графика (часы, обед, шаг сетки) минус существующие записи.
- Редактор графика: режим **«Автоматически»** (часы + обед + шаг) и **«Вручную»**
  (свои окна, например 10:00–14:00 и 16:00–21:00). Есть «Применить ко всем рабочим дням».
- Подтверждение записи, закрытие визита в кассу, заметки и цены сохраняются.
- Уведомления: колокольчик с бейджем непрочитанных, отметка «прочитать все».

Свободные окна на сайте берутся из этого же графика — на следующем шаге это связывается
через API.

## Хостинг

- Один VDS (2 ядра / 2–4 ГБ) и Nginx — держит 30–50 таких статических сайтов.
- Каждый клиент — отдельный `server { ... }` конфиг и свой домен.
- Стоимость одного клиента: ~15–20 ₽/мес + домен .ru ~200 ₽/год.

## Локальный просмотр

Открыть `index.html` в браузере. Для корректной загрузки видео и шрифтов лучше поднять
локальный сервер, но статическая версия работает и без него.
